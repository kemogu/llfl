# Practice answers

For each lesson, create a numbered folder such as `lesson_01/` and write five files: `question_1.py`, `question_2.py`, `question_3.py`, `question_4.py`, and `question_5.py`.

Each file answers the matching coding question at the end of the lesson. Write the answers yourself, run them, then ask me to review the folder. See [the learning plan](../PLAN.md) for the full workflow.

From the repository root:

```bash
python3 languages/python/practice/lesson_01/question_1.py
```

Keep optional experiments in `scratch.py`. Later project lessons may share modules, but retain five answer scripts that demonstrate or test the five requirements.
