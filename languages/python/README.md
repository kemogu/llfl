# Learn Python

Start with the [learning plan](PLAN.md). It defines our schedule, lesson topics, file naming, and review process.

For every lesson:

1. Read its single Markdown lesson file.
2. Complete its five coding questions in five separate `.py` files.
3. Tell me the files are ready so I can review all five.
4. Revise any answers that need correction before moving on.

Save answers in `practice/lesson_01/question_1.py` through `question_5.py`, using a new numbered folder for each lesson.

The initial pace is two lessons per week for 12 weeks, adjusted to your progress. See the [schedule](SCHEDULE.md) and [progress log](PROGRESS.md).

The existing lessons are drafts; we will adapt each lesson to this coding-question format before studying it. **Next up: lesson 1 — Your first Python program.**
