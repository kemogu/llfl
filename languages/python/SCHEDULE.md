# Python study schedule

This is a flexible 12-week plan starting whenever you are ready. The default is **four 45–60-minute sessions per week**, about 3–4 hours weekly or 36–48 hours for the initial course. Project work and revision can take longer. This is an introduction through advanced concepts, not a promise of advanced proficiency in 12 weeks.

## Weekly routine

- **Monday — learn:** read the first lesson, type its examples, predict outputs, then run them.
- **Tuesday — practice:** write five `.py` answers to that lesson's coding questions and request review.
- **Thursday — learn:** study the second lesson and experiment with its examples.
- **Saturday — practice and review:** finish its five answer scripts and request review.

Move these days to fit your life. If you have only two sessions per week, use a 24-week schedule: spend one week on each lesson. Never double the workload to catch up; shift the remaining weeks instead. Capstone week may expand into several weeks.

For a learning session, use about 10 minutes to recall earlier material, 20 minutes to read and type examples, 15–25 minutes to modify and explain them, and 5 minutes to record questions. Use practice sessions for independent attempts before seeking hints.

## Checkpoints and pacing

- **After week 2:** run a script, use variables and input, and explain conditions.
- **After week 4:** transform collections using loops and small functions.
- **After week 6:** demonstrate a working tracker with validation and persistence.
- **After week 8:** explain objects, write behavioral tests, and consume a generator.
- **After week 10:** explain a decorator, a type contract, a performance tradeoff, and an async wait.
- **After week 12:** demonstrate and explain the capstone with passing tests and usable documentation.

Follow the workflow in [PLAN.md](PLAN.md): move forward after all five answer scripts meet their requirements following review, and you can explain your code. Use the next scheduled session for corrections if needed. If a checkpoint feels difficult, add a review week. Speed is less important than understanding.
