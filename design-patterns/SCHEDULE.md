# SOLID and GoF study schedule

Start whenever the [prerequisites](PLAN.md#prerequisites) are comfortable. The default is **two lessons per week for 17 weeks**, using four 45–60-minute sessions per week. Budget roughly 51–68 hours for this first pass, plus extra sessions for projects and corrections. Developing judgment takes continued practice.

| Session | Work |
| --- | --- |
| Monday | Read the first lesson, run the example, and explain the design problem. |
| Tuesday | Write and run the five answers; request review. |
| Thursday | Correct answers first; otherwise study the second lesson. |
| Saturday | Complete its five answers and request review. |

These days are suggestions. Use one lesson per week for a 34-week plan if you are studying other topics alongside this track. Shift remaining lessons when you need extra time; do not double the workload to catch up. All lessons are ready; begin the next lesson after completing the current lesson and its review.

See the [weekly roadmap](PLAN.md#learning-roadmap) for all 34 topics.

## Checkpoints

| After | You should be able to… |
| --- | --- |
| Week 1 | Explain responsibilities, composition, and a behavioral contract. |
| Week 4 | Explain all five SOLID principles and refactor code without changing required behavior. |
| Week 7 | Compare the five creational patterns and identify problems caused by global state. |
| Week 10 | Choose among the seven structural patterns by the problem each solves. |
| Week 16 | Explain the eleven behavioral patterns and choose a simpler solution when appropriate. |
| Week 17 | Demonstrate a tested capstone and accommodate a new requirement with a justified design. |

If a checkpoint is difficult, use the next session for review. Advancement requires all five answers to pass review and an explanation of the design, not simply reaching a calendar date.
