# Learn SOLID and design patterns

Start with the [learning plan](PLAN.md), then follow the [schedule](SCHEDULE.md).

This track uses C++17 and the same workflow as `languages/python`: one Markdown lesson, five coding questions, five answer files, and review before moving on. You write the answers.

The roadmap covers design foundations, all five SOLID principles, all 23 Gang of Four (GoF) patterns, and a capstone. The initial pace is two lessons per week for 17 weeks, with extra time for revisions and projects.

Before starting, be comfortable with functions, classes, composition, object lifetimes, and tests. The C++ prerequisites are listed in the plan.

**All 34 lessons are ready**, each with a C++17 example and five coding questions. Start with [Lesson 01: Responsibilities and behavior](lessons/01-responsibilities-and-behavior.md), then follow the linked [roadmap](PLAN.md#learning-roadmap) in order.
